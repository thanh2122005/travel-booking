- 1 sơ đồ tổng quát hoặc tách 2 sơ đồ:
  - User use case
  - Admin use case

2. ERD / Biểu đồ lớp thực thể
- Các bảng/thực thể chính:
  User, Tour, Location, Booking, Review, Favorite, ContactInquiry, NewsletterSubscriber, TourImage, Itinerary

3. Sơ đồ kiến trúc hệ thống
- Client -> Next.js -> API/Backend -> Prisma -> MySQL
- Có thể thêm NextAuth, Cloudinary, phân quyền Admin/User

4. Sơ đồ luồng xử lý / Sequence / Activity
- Đăng nhập
- Đặt tour
